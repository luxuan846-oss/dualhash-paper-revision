\section{Introduction}

\label{Section: Introduction}
% A key technique in large-scale image retrieval systems is hashing. Image hashing aims to represent the information of an image using a binary code (e.g.,\( \pm 1\)) for efficient storage and accurate retrieval \cite{L2H2009}. Recently, deep learning to hash has shown significant improvements due to its robust feature extraction capability \cite{luoSurveyDeepHashing2023,xiaSupervisedHashingImage2014}, which utilizes neural networks to map high-dimensional feature vectors (e.g., 1024 dimensions) into compact binary codes (e.g., 64 bits). 
Hashing is a pivotal technique in large-scale image retrieval, which encodes image content into compact binary codes (e.g., $\pm 1$) for efficient storage and accurate similarity search \cite{L2H2009}.
% Recently, deep hashing has achieved significant advances by leveraging neural networks to compress high-dimensional feature vectors (e.g., 1024-dimensional float32 representations, totaling 32,768 bits) into compact binary codes (e.g., 64 bits), achieving a compression ratio of up to $512\times$ while maintaining competitive retrieval accuracy . 
Deep hashing further leverages neural networks to map high-dimensional features into binary codes, achieving substantial compression (e.g., $512\times$) while maintaining competitive retrieval accuracy \cite{luoSurveyDeepHashing2023}. 
The mainstream approaches can be broadly classified into two categories: sign-based methods and continuous relaxation. However, a fundamental challenge in deep hashing arises from the discrete nature of quantization. The $\text{sgn}$ function used to generate binary codes has zero gradients almost everywhere, which renders standard first-order methods ineffective in training deep hashing networks \cite{Cao2017HashNetDL}. Continuous relaxation methods have been explored to address this issue, but inevitably introduce \textbf{quantization error:} the discrepancy between the optimized continuous values and the final discrete values \cite{weissSpectralHashing2008}.

To mitigate this issue, researchers have developed specialized regularization techniques \cite{caoDeepCauchyHashing2018,li2017deep,liuDeepSupervisedHashing}. Among them, W-type regularizations, such as \(| |z| - 1| \), have proven effective.
These regularizers impose sharp penalties to encourage variables towards binary values (e.g., $-1$ or $1$). Mathematically, this approach naturally formulates deep hashing as a nonconvex composite optimization problem\footnote{A formal definition of this problem is provided in \Cref{Section: Problem Reformulation}.}:
\begin{align}
\label{Eq: the general nonlinear composite problem in intro}
\min_{\bx \in \calX} \quad \frac{1}{n} \sumn f_i (\bx) + \sumn h(\bD_i(\bx)),
\end{align} where \(f_i\) and \(\bD_i\) are continuously differentiable and \(h\) is a proper and lower semi-continuous (l.s.c.) regularizer. Classic examples include the 
\(\ell_1\) norm to introduce sparsity \cite{tibshirani1996regression} and the \(\ell_2\) norm weight decay to prevent overfitting \cite{tikhonov1943stability}. In practice, researchers typically apply stochastic (sub)gradient methods (SGD) directly \cite{bottou2018optimization,Kingma2014AdamAM} to optimize the objective \eqref{Eq: the general nonlinear composite problem in intro}, and deep hashing follows this paradigm as well \cite{wu2025fth,he2025mambahash}. This seemingly effective choice, however, frequently leads to suboptimal performance. The regularizer is often nonsmooth around some regions; using subgradients may result in slow convergence and oscillation.

% Proximal-based methods offer a promising solution for composite optimization. 
\blue{The proximal operator is a powerful tool for handling the nonsmoothness of regularizers. For the special case $\bD_i(\bx) = \bx$, stochastic proximal gradient methods (SPGD) and their variance-reduced or momentum-based variants have been extensively studied~\cite{li2022simple,tran2022hybrid,xu2023momentum,gaoNonConvexStochasticComposite2024}. However, these methods require regularizers with tractable proximal operators (e.g., $\ell_1$ soft-thresholding). Although the W-type regularizer admits a closed-form proximal operator~\cite{bai2019proxquant} (\Cref{Fig: the W and V regularizations}), its composition with neural network outputs $h(\bD_i(\bx))$ renders the proximal subproblem intractable, making SPGD inapplicable to Problem~\eqref{Eq: the general nonlinear composite problem in intro}. Moreover, unlike standard deep learning tasks, where regularization is typically imposed on model parameters (e.g., weight decay), deep hashing requires regularization directly on the network output to enforce binary codes, as illustrated in \Cref{Fig:comparison_classification_vs_hash}.} This makes the nonsmooth composite form \(h(\bD_i(\bx))\) intrinsic to deep hashing and therefore necessary to handle explicitly.

We demonstrate this distinction by comparing with a basic classification task in \Cref{Fig:comparison_classification_vs_hash}. While classification directly employs network outputs for prediction, deep hashing requires generating binary hash codes for downstream retrieval tasks. This unique requirement leads to W-type regularization, which typically constrains the final network output rather than focusing on parameter properties. Therefore, it is necessary to consider the nonsmooth form explicitly.

For nonsmooth compositional optimization, including Problem~\eqref{Eq: the general nonlinear composite problem in intro}, significant research has been conducted when \(h\circ \bD\) is either convex~\cite{zhang2020optimal,wang2024alexr} or weakly convex~\cite{davis2019,Drusvyatskiy2019,wang2024,hu23}. \blue{For instance, \(h\circ \bD\) is weakly convex when \(h\) is convex and \(\bD\) is smooth~\cite{davis2019,Drusvyatskiy2019,wang2024}, or when \(h\) is component-wise nondecreasing and \(\bD\) is weakly convex~\cite{hu23}.} However, when $h$ itself is nonconvex, as in our setting, $h \circ \bD$ is not necessarily weakly convex, rendering these methods inapplicable. For the case where $h$ is nonconvex, \cite{Bolte2018} reformulates the problem as a constrained optimization by imposing redundant variables and establishes asymptotic convergence via a Lagrangian-based approach. 
% More recently, h is either Lipschitz not necessary convex \cite{yao2024note} , providing $\mathcal{O}(1/(\delta\epsilon^2))$ iteration complexity result for finding a $(\delta, \epsilon)$-stationary point. \cite{zhang2025complexity} conducts a systematic analysis covering scenarios where $h$ is nonconvex with or without Lipschitz continuity. 
\blue{When \(h\) is Lipschitz continuous but possibly nonconvex, \cite{yao2024note} establishes an \(\mathcal{O}(1/(\delta\epsilon^2))\) iteration complexity for finding a \((\delta,\epsilon)\)-stationary point. More recently, \cite{zhang2025complexity} provides a systematic analysis for the cases where \(h\) is nonconvex with or without Lipschitz continuity.} Among their results most relevant to ours, they establish an $\mathcal{O}(\epsilon_1^{-2} \epsilon_2^{-1})$ iteration complexity for finding an $(\epsilon_1, \epsilon_2, 0)$-stationary point for Lipschitz continuous $h$, along with subsequential convergence results. However, all consider only the \emph{deterministic} setting, whereas ours addresses the \emph{stochastic} finite-sum formulation that naturally arises in large-scale deep hashing; directly extending their results to our setting is nontrivial.

\subsection{Contributions}
In this paper, we propose an efficient deep hashing algorithm to address these challenges posed by nonlinear composition with W-type regularization. Our approach presents a reformulation of the W-type regularized problem using a decouple scheme and designs a new primal-dual algorithm using Fenchel duality. We aim to bridge the theoretical-practical gap by providing rigorous non-asymptotic convergence analysis and enhanced practical performance in deep hashing. 
Our main contributions are as follows:
\begin{itemize}[leftmargin=2em]
\item {\textbf{Novel primal-dual deep hashing algorithm.}} We reformulate deep hashing models with W-type regularization as a two-block finite-sum optimization problem \eqref{Prop: block-wise regularized problem}, decoupling the challenging composite term $h(\bD(\bx))$ and facilitating sequential convergence analysis. Grounded in this formulation, we propose \textit{DualHash}, a stochastic primal-dual algorithm for deep hashing. Using Fenchel duality, we partially transform the nonconvex W-type regularization optimization into a convex dual formulation that admits closed-form updates, ensuring robustness and stable convergence. We then develop two important instances: a momentum-based implementation (\textbf{DualHash-StoM}) and a variance-reduced implementation using StoRM (\textbf{DualHash-StoRM}).
\item {\textbf{Comparable complexity guarantee.} We provide rigorous non-asymptotic complexity analysis for deep hashing optimization under the challenging stochastic, nonconvex, multi-block primal-dual framework.} Specifically, to attain stochastic critical points of Problem \eqref{Prop: block-wise regularized problem}, we establish an $\mathcal{O}(\varepsilon^{-4})$ oracle complexity result for DualHash-StoM and, under the mean-square smoothness condition, an improved $\mathcal{O}(\varepsilon^{-3})$ complexity result for DualHash-StoRM, matching the best-known lower bound for stochastic optimization~\cite{arjevani2023lower}. Table~\ref{Table: summary of deep hashing algorithms} summarizes the comparison with existing deep hashing methods.
\item {\textbf{Superior empirical performance.} Extensive experiments on three widely-used datasets} demonstrate the practical effectiveness of DualHash. In particular, the proposed method achieves consistently lower quantization errors across different bit lengths compared to baselines, validating the advantages of our primal-dual framework.
\end{itemize}
