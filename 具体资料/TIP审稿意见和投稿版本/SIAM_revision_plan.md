# DualHash 转投 SIAM 返修路线图

## 目标

把现有 TIP 返修意见转化为一套适合 SIAM 审稿口味的修改方案：弱化“纯 benchmark 追新”的叙事，强化“问题建模 + 算法设计 + 收敛理论 + 机制解释 + 可复现性”。

## 一、可以立刻完成的文稿修改

### 1. 清理语言和结构硬伤

- 重写 `sections/related_work.tex` 中残留的草稿句、断裂表述和非正式措辞。
- 在实验设置中明确公平性原则：数据划分、backbone、预处理、early stopping、评价指标保持一致。
- 在结论中增加“StoRM 收敛更快但 StoM 检索更好”的机制性解释。
- 在 16-bit 分析中明确“separability-semantics trade-off”。

### 2. 让论文更像 SIAM，而不是 TIP 返修稿

- 把主叙事从“我们比谁都强”调整为“我们解决了一个此前缺乏复杂度保证的非凸复合优化问题”。
- 把实验部分中的表述改为支持理论主张和机制分析，而不是只强调榜单排名。
- 在引言和结论中减少过度营销式语言，突出方法适用范围、限制和未来方向。

### 3. 可以通过补文字部分回应的审稿点

- `StoRM vs. StoM` 理论与实验不一致：
  已可通过现有学习曲线和量化误差分析补出较完整解释。
- `16-bit` 表现偏弱：
  已可基于当前直方图和 quantization error 图补一段更有说服力的机理分析。
- 训练一致性：
  已可在实验设置中补充说明。
- ELU 假设实用性：
  若暂时没有 ReLU 消融，可在 discussion 中明确这是理论分析所需条件，并列为未来工作。
- 内存开销：
  若暂时没有新实验，可在 discussion 中诚实说明 primal-dual 变量会带来额外存储，并把大规模内存优化列为后续工作。

## 二、必须补实验后再投更稳的部分

### 1. 新基线

这是当前最可能被继续质疑的部分。若转投 SIAM，未必需要追求最全 CV 顶会 benchmark，但至少要避免“baseline 太旧”的明显短板。

建议最低配置：

- 保留 `HashNet / OrthoHash / MDSHC`
- 增补 `GreedyHash`
- 增补 `CSQ`
- 如能做到，再加一个 2024--2025 方法或 Transformer-based hashing 方法

### 2. 更大规模数据集

如果没有 `MS COCO` 或 `ImageNet-1K`，建议至少补一个：

- 偏稳妥：`MS COCO`
- 偏强调规模：`ImageNet-1K`

如果时间或算力有限，至少把 `MIRFlickr-25K` 加上，能增强多标签说服力，但它不能完全替代真正的大规模实验。

### 3. 方差与时间/内存

建议补三张轻量表：

- 主结果表增加 `mean ± std`
- 训练时间对比表
- 显存或内存占用表

这三项工作量通常低于补大规模 benchmark，但能显著提高论文完整性。

## 三、建议的返修顺序

### 阶段 A：先把文稿打磨到“可继续扩展”

1. 清理 related work、实验设置、结论和 discussion。
2. 统一术语、图表 caption 和贡献表述。
3. 检查参考文献格式错误和重复定义。

### 阶段 B：补最关键的新证据

1. 补 `GreedyHash / CSQ`。
2. 补一个更大规模或更标准的多标签数据集。
3. 补 `mean ± std` 和 wall-clock time。

### 阶段 C：决定 SIAM 版本侧重点

如果实验资源充足：

- 走“理论 + 机制 + 较完整实验”路线。

如果实验资源有限：

- 走“理论贡献主导 + 必要实验验证 + 诚实讨论局限”路线，
- 但仍建议至少补 2 个有代表性 baseline。

## 四、我建议你接下来优先做的事情

最优先不是继续润色句子，而是尽快确认两件事：

1. 你是否还能补实验，尤其是 `GreedyHash / CSQ / MS COCO`。
2. 你准备投的具体 SIAM 期刊是哪个。

因为不同 SIAM 期刊对“应用实验密度”和“理论深度”的容忍度差别很大。例如更偏优化/计算数学的期刊，会比 TIP 更接受“理论主导 + 有限但扎实实验”的结构。

## 五、当前版本的真实状态判断

现在这稿子已经有一个不错的理论骨架，也有机制分析的雏形，但若直接按当前实验配置转投，最危险的点仍然是：

- baseline 偏旧
- 缺少更大规模数据集
- 缺少时间/内存/方差这类“完整性证据”

也就是说，这篇稿子不是“不能投”，而是“还差一轮非常明确的补强”。最值得投入时间的不是再修语言，而是把证据链补完整。
